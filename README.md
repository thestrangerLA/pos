# POS ร้านค้า (Web Point of Sale System)

ระบบจุดขายหน้าร้าน (Point of Sale) แบบเว็บแอปพลิเคชัน Standalone ใช้งานง่าย รองรับอุปกรณ์ทั้งมือถือ แท็บเล็ต และคอมพิวเตอร์ ทำงานออฟไลน์ได้ (เก็บบันทึกข้อมูลผ่าน LocalStorage ภายในเครื่อง)

## ✨ ฟีเจอร์หลัก (Key Features)

- 🛒 **ระบบขายหน้าร้าน (POS)**: เลือกสินค้าใส่ตะกร้า คำนวณยอดเงิน ส่วนลด และช่องทางชำระเงิน (เงินสด / QR Code)
- 📦 **จัดการสินค้าและสต็อก (Products & Stock)**: เพิ่ม แก้ไข ลบสินค้า กำหนดหมวดหมู่ ราคาขาย และราคาทุน
- 📊 **รายงานและแดชบอร์ด (Analytics & Reports)**: ยอดขายรายวัน สินค้าขายดี กราฟแสดงสถิติ และรายงานกำไร-ขาดทุน (P&L)
- 🧾 **ใบเสร็จ / Invoice**: ดูประวัติบิลย้อนหลัง และออกใบเสร็จรับเงิน
- ⚙️ **ตั้งค่าร้านค้า**: กำหนดชื่อร้าน ที่อยู่ เบอร์โทร เลขประจำตัวผู้เสียภาษี สัญลักษณ์สกุลเงิน และรูป QR รับเงิน
- 🌓 **ธีมมืด / ธีมสว่าง (Dark & Light Mode)**: รองรับการแสดงผลทั้งแบบสว่างและมืดตามความสะดวกในการใช้งาน
- 💾 **จัดเก็บข้อมูลในตัว (Offline-first)**: ใช้งานได้ทันทีโดยไม่ต้องต่อฐานข้อมูลภายนอก ข้อมูลบันทึกไว้ในเบราว์เซอร์

## 🚀 การติดตั้งและเปิดใช้งาน (Getting Started)

### เปิดใช้งานผ่านเบราว์เซอร์
เปิดไฟล์ `index.html` หรือ `pos.html` บนเว็บเบราว์เซอร์ใดก็ได้ เช่น Google Chrome, Safari, Microsoft Edge หรือ Firefox

### เปิดใช้งานผ่าน GitHub Pages
1. ไปที่แท็บ **Settings** ของ Repository บน GitHub
2. เลือกเมนู **Pages** ทางด้านซ้าย
3. ในส่วน **Build and deployment** > **Branch** ให้เลือก `main` และโฟลเดอร์ `/ (root)` จากนั้นกด **Save**
4. ระบบจะสร้าง URL สำหรับเข้าใช้งานให้อัตโนมัติ เช่น `https://<username>.github.io/<repository-name>/`
