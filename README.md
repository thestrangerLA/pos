# POS ຮ້ານຄ້າ (Web Point of Sale System - ພາສາລາວ)

ລະບົບຈຸດຂາຍໜ້າຮ້ານ (Point of Sale) ແບບເວັບແອັບພລິເຄຊັນ Standalone ໃຊ້ງານງ່າຍ ຮອງຮັບອຸປະກອນທັງມືຖື, ແທັບເລັດ ແລະ ຄອມພິວເຕີ ເຮັດວຽກອອບລາຍໄດ້ (ບັນທຶກຂໍ້ມູນຜ່ານ LocalStorage ພາຍໃນເຄື່ອງ)

🎨 **ຮູບແບບສີ (Theme):** ແດງ, ເຫຼືອງ, ຂາວ (Red, Yellow, White)  
🔤 **ຟອນ (Font):** Noto Sans Lao  
🇱🇦 **ພາສາ (Language):** ພາສາລາວ (Lao Language)

---

## ✨ ຄຸນສົມບັດຫຼັກ (Key Features)

- 🛒 **ລະບົບຂາຍໜ້າຮ້ານ (POS)**: ເລືອກສິນຄ້າໃສ່ກະຕ່າ ຄຳນວນຍອດເງິນ ສ່ວນຫຼຸດ ແລະ ຊ່ອງທາງຊຳລະເງິນ (ເງິນສົດ / QR Code / ແບ່ງຈ່າຍ)
- 📦 **ຈັດການສິນຄ້າ ແລະ ສະຕັອກ (Products & Stock)**: ເພີ່ມ, ແກ້ໄຂ, ລຶບສິນຄ້າ ກຳນົດໝວດໝູ່ ລາຄາຂາຍ ແລະ ຕົ້ນທຶນ ພ້ອມແຈ້ງເຕືອນສິນຄ້າໃກ້ໝົດ
- 📊 **ລາຍງານ ແລະ ແດຊບອດ (Analytics & Reports)**: ຍອດຂາຍລາຍວັນ ສິນຄ້າຂາຍດີ ກຣາຟສະຖິຕິ ແລະ ລາຍງານກຳໄລ-ຂາດທຶນ (P&L)
- 🧾 **ໃບເກັບເງິນ / Invoice**: ອອກໃບເກັບເງິນ ສາມາດດາວໂຫຼດເປັນໄຟລ໌ PDF ຫຼື ສັ່ງພິມໄດ້ທັນທີ
- ⚙️ **ຕັ້ງຄ່າຮ້ານຄ້າ**: ກຳນົດຊື່ຮ້ານ ທີ່ຢູ່ ເບີໂທ ເລກປະຈຳຕົວຜູ້ເສຍພາສີ ສັນຍະລັກເງິນ (₭, ฿, $) ແລະ ຮູບ QR ຮັບເງິນ
- 🌓 **ໂໝດມືດ / ໂໝດສະຫວ່າງ (Dark & Light Mode)**: ຮອງຮັບທັງແບບສະຫວ່າງ ແລະ ແບບມືດ
- 💾 **ເກັບຂໍ້ມູນໃນຕົວ (Offline-first)**: ບໍ່ຈຳເປັນຕ້ອງເຊື່ອມຕໍ່ຖານຂໍ້ມູນພາຍນອກ ຂໍ້ມູນຖືກບັນທຶກໄວ້ໃນບຣາວເຊີຢ່າງປອດໄພ
